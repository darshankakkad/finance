# Financial data visualisation and analysis

This is a random collection of my codes on financial data analysis. 

* <code style="color : Red">stock_movements_piechart.ipynb</code>: Shows a time series plot of a stock and a pie chart depicting the stock price movements
* <code style="color : Red">stock_correlations.ipynb</code>: Makes a correlation heatmap for any input stocks
* <code style="color : Red">asset_allocation.ipynb</code>: Calculating portfolio returns using manually defined weights
